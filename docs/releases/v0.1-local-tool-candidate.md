# v0.1 Local Tool Candidate

Date: 2026-06-15

## What Shipped

- Primary operator workflow: `krn run`.
- Run result artifacts: `.krn/current/run-result.json` and
  `.krn/current/run-result.md`.
- Run bundle: `.krn/current/run-bundle/`.
- Supporting report and release-check gates.
- Local verify execution policy with explicit `--execute`, allowlisted commands,
  no shell mode, scrubbed env, timeout limits, and compact redacted output.
- Downstream install/config/uninstall lifecycle.
- Deterministic review, summary, report, eval, doctor, artifact, and memory
  surfaces.

## How To Run

```bash
pnpm install
pnpm verify:local
pnpm --silent krn run --task "Local v0.1 smoke" --execute-verify --bundle
```

Use a task spec for real target work:

```bash
pnpm --silent krn run --task-spec <task.json> --execute-verify --bundle
```

## Known Non-Goals

## Known Risks

- Local run evidence can be mistaken for production proof.
- Hook diagnostics can be mistaken for hook trust.
- Target proof is isolated-worktree evidence, not a target commit or push.
- Historical `.krn` artifacts can create report caveats.
- Context selection still needs more real-repo variation.
