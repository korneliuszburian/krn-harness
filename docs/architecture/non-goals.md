# Non-Goals

P0 intentionally does not build:

- Dashboard.
- MCP server.
- Multi-agent orchestrator.
- Vector database or semantic embeddings.
- Full AST, callgraph, dataflow, or Tree-sitter graph.
- Production WordPress/ACF detector.
- Browser/Playwright evidence layer.
- GitHub Action.
- Plugin distribution.
- Autonomous researcher.
- Auto-approved memory.
- Many downstream runtime skills.

These are deferred until the P0 contract, context, trace, verify, and governance surfaces have evidence.
